The For-Profit ministry of Alderpen Media, Inc. has been hard at work creating H@MEWORX (pronounced home-works). The software is designed to be an administrative shell with various base functions to handle users, permissions, backups, integrations, cron-based tasks, etc. while allowing the enhancement of the software by installing various modules.

The software is being built by George Benson, on behalf of, and as an agent of, Alderpen Media, Inc., with the assistance of AI tools including Claude Code (AI). It's being built specifically for Alderpen Media, Inc.'s own internal use — but parts will be shared freely with the hope that others may find it useful.

The software is designed to be self-hosted in a Docker-style container on a home-based internal network.

H@MEWORX is designed and tested for exactly one environment: a single self-hosted instance on a private home or small-business network, serving a small number of users. It has not been tested for direct exposure to the public internet, for multi-tenant use, for large numbers of users, or for any high-availability or production hosting scenario. Deploying it outside its intended environment is entirely at your own risk, and it is your responsibility to secure any system you expose.
